Phase 1 — Logging + JSON (Đã xong)
Module: MathLogger (JSONL data/math_history.json)
Workload: nhẹ, CPU, file I/O
Goal: Lưu mọi interaction, timestamp, success flag.
Quan trọng: thiết kế format dễ parse (mỗi dòng 1 JSON object) — bạn đã làm đúng.

Phase 2 — Pattern Recognition (Đã xong)
Module: PatternRecognizer
Workload: CPU, string ops, map count
Goal: Trích features, thống kê, tìm tương tự, suggest method
Output: ai_knowledge.json (summary, rates, examples)

Phase 3 — Vietnamese Parser (NLP cơ bản)
Module: vietnamese_parser
Workload: CPU, regex/tokenize
Goal: Chuyển ngôn ngữ tự nhiên → biểu thức chuẩn (normalize: "tính 2 cộng 3" → "2+3")
Lợi ích: UX tốt hơn, nguồn dữ liệu text đời thực usable

Phase 4 — Reasoning Engine (Case-Based Reasoning — CBR)
Module: reasoning_engine
Workload: CPU; small ML-style heuristics (similarity, weighting)
Goal: Nếu có case tương tự (score >= threshold), dự đoán kết quả từ lịch sử mà không gọi Calculator.
Tư duy: "Nếu đã từng giải bài tương tự thành công → reuse solution"
Outcome: AI bắt đầu trả lời, không chỉ gợi ý.

Phase 5 — Adaptive Learning / Lightweight ML
Module: experimental LSTM/Transformer/ensembles (optional)
Workload: CPU → bắt đầu cần GPU cho training lớn
Goal: Học model để classify/suggest/predict với vector features; có thể fine-tune trên data lớn.
Khi nên dùng GPU: khi bạn huấn luyện models với ma trận lớn / nhiều epochs.

Phase 6 — Distributed / Networked Learning
Module: network layer + sync logic + DB server
Workload: multi-node, cloud, có thể cần GPU cluster
Goal: Share knowledge across instances, federated updates, centralized DB, REST / gRPC API.
